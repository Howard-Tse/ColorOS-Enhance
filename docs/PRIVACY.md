## 模块运行时数据

- 「模块状态」可手动保存 ZIP 诊断包。报告包含模块、ColorOS、Android 与系统组件版本、机型、关键 Hook 状态和时间，最多保留最近 24 小时内的 512 条事件。「同时导出系统接口」会在保存时读取指定系统组件的 APK 声明，附上关键类、方法签名、字段类型和指令引用。Seedling SDK 的版本优先由 SystemUI 作用域从当前加载的归档读取。SDK 未加载时，报告会注明是否从 SystemUI 的原厂 SDK 归档读取。接口开关开启时一并采集其关键方法。诊断不导出完整 APK、字节码、字符串常量、安装路径或运行时参数，也不读取系统日志、通知正文、账号、媒体内容、SIM PIN 或设备序列号。应用不会自动上传诊断包。

- 设置保存在本机，不包含维护者的手机配置或凭据文件。1.30.0 未声明 INTERNET 权限；1.31.0 为启动时及手动更新检查新增该权限。
- 默认在应用进入前台时检查一次，有更新才弹窗。关闭「启动时提醒新版本」后停止启动检查；选择「跳过此版本」会在本机记录对应版本码。进入二级页面、旋转屏幕不重复检查。默认查正式版，用户可在更新页开启预发布版检查，此选择保存在本机。点击「检查更新」进入更新页或点按「重新检查」也会请求公开发布信息。所有检查通过 HTTPS 访问 GitHub 官方 API，不带账号令牌，不上传配置、SIM 信息、媒体内容或设备标识。GitHub 会收到请求来源 IP。没有后台定时检查、统计或追踪。内嵌系统设置中的手动入口也由模块应用完成请求，不在设置或 SystemUI 进程联网。
- 仓库／发布页和 APK 下载通过用户选择的浏览器打开，网络访问遵循浏览器与 GitHub 各自的规则。模块不静默下载、确认安装或自动重启。
- SIM PIN 由用户在手机输入，通过模块的受保护桥接和加密存储流程处理；正式凭据在电话进程一侧管理。不要把 PIN 或完整 ICCID 填入公开 Issue。关闭功能并不等于删除已保存的凭据。
- 实时律动在本机采样并显示频段高度。显式开启「音效兼容采样」后，遇到音效冲突时可改用系统输出混音，柱高可能受其他应用的声音影响。音频样本只在内存中用于计算，不保存或上传。
- 安装器列表、媒体信息与系统接口用于相应本机功能；模块配置不是发布包的一部分。
- 通知转流体云默认关闭、白名单为空。开启后在 SystemUI 进程内使用已有通知集合，按规则生成卡片，正文、图片与原始 PendingIntent 仅在内存中使用，不写入模块设置、不上传。默认在锁屏时恢复原通知。开启「锁屏时保留通知转流体云」后，仅对系统允许在锁屏完整显示的通知继续转换；需要隐藏、脱敏或无法判断权限的通知沿用系统展示。可另行开启「锁屏时显示通知流体云卡片」，让允许完整展示的卡片在原通知有效期间保留在锁屏通知列表。系统收紧锁屏权限时会重新判断。锁屏卡片最多保留两个原通知的普通操作；需要身份验证或快捷回复的操作留给解锁后的原通知。收纳页在解锁后可打开。关闭功能或转换失败时恢复原通知。点击清除，或选中了「清除原通知和卡片」后成功打开通知时，才按系统流程清除可清除的原通知。
- 关闭原通知声振时，SystemUI 与系统框架通过有调用方校验的本机接口交换转换组件的在线状态。在线状态仅在内存中使用。
- 通知应用筛选需要本机已安装应用列表；渠道查询只交换应用包名、通知渠道名称及 ID，结果短时保存在内存。它不授予第三方读取通知的权限，也不把通知正文传给设置应用。收纳入口直接显示在系统通知中心。通知显示权限仅用于用户手动发送的模块自测通知。

旧包迁移经 root 授权后只读获取指定普通参数和启用状态，结果留在本机私有空间；不把 PIN、ICCID 或密钥写入迁移结果，不直接改写框架数据库或静默卸载应用，详见[迁移说明](MIGRATION.md)。

以上描述限定于本模块；LSPosed、系统及第三方应用各自的数据处理行为不由本项目控制。

## 提交问题时

可以提供模块版本、Android／ColorOS 版本、相关开关、简短复现步骤和必要的脱敏错误片段。机型与固件版本通常有助于兼容分析，无需提供设备唯一标识。

上传前遮挡通知正文、账号、头像、地址、订单／取餐码、二维码、媒体私密内容、IMEI、ICCID、MAC 和设备序列号。仅裁剪到相关 UI 区域；不要公开整份 bugreport、完整日志、应用数据、签名文件或密钥备份。

## 发布复查

`scripts/Audit-Publish.ps1` 检查当前待提交文件中的高风险文件、疑似设备标识、个人路径和常见秘密格式，只报告位置，不回显匹配值。`-Apk` 可额外检查本地 APK 的内容标记和异常归档项。

扫描结果为“未发现匹配项”不等于绝对不存在个人信息。提交前还应检查新增文字、图片／视频、二进制、Git 作者信息和 Release 附件。APK 的签名证书与指纹是公开验证信息，私钥和密码始终不公开。
