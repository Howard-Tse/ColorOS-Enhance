# 通知转流体云

开启「合并同类通知」后，通知中心与锁屏列表中的分组卡片默认展示最新一条，支持原厂媒体分页组件的系统会在卡片底部显示分页圆点，左右滑动可跟手切换同组通知，正文和按钮对应当前页。翻到第一页或最后一页后继续向外滑动，交由系统处理该行的滑动手势。只有一条时隐藏页标。锁屏页数只计入系统允许完整显示的成员。缺少媒体分页组件的固件可从长按菜单查看本组通知。

自 1.32.0 起，两处设置均可通过「流体云 → 通知转流体云」打开此功能，各项设置直接列在总开关下方。

默认关闭，采用空白名单；持续／进度、普通通知默认仅生成胶囊，静默与标准通话通知默认不转换。静默按通知和渠道的重要程度判断，不以手机的响铃模式判断。系统关键提醒、已有原生流体云、媒体通知及其他用户／工作资料通知保持原系统处理。

可切换白名单／黑名单，两份选择分别保留。每次打开快捷名单时，已保存勾选的应用排在前面。「逐应用设置」有独立页面，可管理两份名单、浮窗打开、应用默认行为和渠道规则。渠道规则先于应用默认行为和通知类型，仍须满足应用筛选。可查询实际渠道名称和 ID；若查不到，可先让应用发出一条通知后刷新，也可手动输入 ID。

转换成功后默认将原通知收纳到「已转为流体云卡片」。入口排列在通知列表尾部，由 SystemUI 绘制，最多显示四个来源应用图标。点击后进入原生收纳页，通知中心和收纳页的「×」分别清理当前列表中可清除的通知。也可设置保留或隐藏原通知，另有独立开关把转换后的卡片显示在通知中心。只有原生卡片和收纳入口准备好后才收纳，关闭功能或解析失败时恢复原通知。默认锁屏时也恢复原通知。开启「锁屏时保留通知转流体云」后，可另行打开「锁屏时显示通知流体云卡片」，在锁屏通知列表保留系统允许完整展示的卡片。卡片跟随原通知更新，在原通知结束、卡片被清除或锁屏权限收紧时移除。锁屏卡片最多显示两个原通知的普通操作，沿用应用提供的按钮和点击目标。展开卡片后可长按打开 ColorOS 菜单并使用原通知操作。合并同类通知时，选择「查看本组」会打开通知中心的收纳页，定位并展开对应的原生通知组。如果这组成员没有对应的系统分组，或原通知设为保留、隐藏，收纳页会临时只展示这一组的原始通知。横向滑动卡片清除可清除的原通知，持续通知则回到通知中心。需要快捷回复或认证时会打开原通知。

收纳和隐藏模式会替代原横幅，原横幅会在转换超时后按系统流程显示。默认保留系统响铃和震动，关闭需要启用系统框架作用域并重启手机。点击打开后默认不清除，也可选择只移除流体云，或一起清除原通知和卡片。选择一起清除时，系统不允许清除的持续通知仍会保留流体云。「前台应用内保留流体云胶囊」默认关闭，沿用 ColorOS 对来源应用在前台时的显隐逻辑。打开后跳过该隐藏规则，适用于状态栏内的各类流体云胶囊。

卡片按应用／会话合并，可关闭合并。原生候选数量限制只在存在转换通知时调整，展开列表使用系统卡片列表滚动。通知胶囊可限制最大宽度，右侧可显示通知内容或应用名。进度样式仅在通知实际提供进度时使用。ColorOS 支持把原通知目标打开到浮窗时，长按菜单会提供「浮窗打开」。直接显示在卡片上的浮窗按钮默认关闭，可全局设置或按应用覆盖。自动展开受锁屏、勿扰、频率和当前交互状态约束。

可使用「发送模块自测通知」验证进度、更新、按钮、多条通知和撤销，不需要使用真实聊天或订单测试。通知转换复用 SystemUI 通知集合与原生流体云渲染，不启用第二个通知监听服务。不同固件依靠接口能力检测；接口不匹配时保留原通知。

控制中心纵向展开的「滚动到边界时震动」独立配置、默认关闭，优先使用系统列表边界触感，不绕过系统触感设置；回弹帧或布局复位不会重复触发。
